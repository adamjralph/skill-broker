# Foundation and Brokered are profile-relative roles

A Skill is neither foundation nor brokered in itself; those words describe how one
profile exposes it. The same Skill may be a Foundation Skill for one profile and a
Brokered Skill for another.

A Skill therefore carries no global foundation/brokered classification. Profile policies
must validate their Foundation Set and Brokered Allowlist as disjoint.
