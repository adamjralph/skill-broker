# v1 judgment is a single primary skill plus dependency closure

The first Judgment schema returns one Primary Skill, its confidence, and an explicit
no-skill outcome. Further skills enter only through Dependency Closure.

_Considered options_: multi-skill selection. Deferred, not rejected: it is added only if
Stage 5 evaluation shows reviewed cases requiring two independent primaries. That is the
recorded falsification condition, so the deferral stays honest rather than permanent.
